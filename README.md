# 沈小科学生端 MVP

沈阳科技学院 Agent 集成微信小程序第一阶段学生端，使用原生微信小程序技术开发。

## 技术说明

- 原生 WXML、WXSS、JavaScript
- 本地 Mock 数据和微信本地存储
- 不依赖真实校园接口
- 不包含任何 API Key
- 学习、生活、记账三个 Agent 的会话和消息按类型隔离

## 本地运行

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本仓库根目录。
4. AppID 可使用测试号，或替换 `project.config.json` 中的 `touristappid`。
5. 点击编译。

## 开发阶段

项目按页面骨架、独立会话、学习与生活、AI 记账、语音录入和最终检查分阶段提交。
