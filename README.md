# 沈小科学生端 MVP

沈阳科技学院 Agent 集成微信小程序第一阶段学生端，使用原生微信小程序技术开发。

## 技术说明

- 原生 WXML、WXSS、JavaScript
- 本地 Mock 数据和微信本地存储
- 不依赖真实校园接口
- 不包含任何 API Key
- 学习、生活、记账三个 Agent 的会话和消息按类型隔离

## 本地运行

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本仓库根目录。
4. AppID 可使用测试号，或替换 `project.config.json` 中的 `touristappid`。
5. 点击编译。

## 本地检查

项目没有 npm 依赖，可直接使用 Node.js 运行服务层检查：

```powershell
node tests/agentService.test.js
node tests/accountingService.test.js
```

## 微信开发者工具验收路径

- 首页：确认四项底部导航、三类 Agent 入口、课程/待办/活动/支出摘要可见。
- 学习：切换今日/本周课表，新增、完成、删除 Todolist，进入学习助手并发送“今天有什么课？”。
- 生活：按分类和关键词筛选活动，打开活动详情；在请假页生成文本，确认后保存；使用餐食推荐和生活助手。
- AI 记账：输入“午饭10元”，识别后确认入账；检查最近账单、余额和分类统计；再测试“早餐6元，午饭12元”和“工资到账5000元”。
- 会话隔离：从学习、生活、记账分别新建会话，确认历史列表、消息和删除操作互不串数据。
- 语音回退：进入 AI 记账点击“语音录入”，结束后会填入 Mock 文本“午饭10元”，可编辑后继续识别。

所有业务数据通过 `wx.setStorageSync` 和 `wx.getStorageSync` 保存。账单只有点击“确认入账”后才写入；删除记账 Agent 会话不会删除账单。
